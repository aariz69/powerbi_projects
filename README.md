powerbi_project using sql and dax queries 
Credit Card Analytics Dashboard (Power BI)
Key Features
📌 Real-time Data Integration
Connected Power BI with SQL database to enable automatic data updates
📈 Revenue & Transaction Analysis
Tracked total revenue, interest earned, and transaction trends over time
👥 Customer Segmentation
Analyzed customers based on:
Age group
Income group
Job category
💳 Card Category Insights
Compared performance across different card types (Blue, Silver, Gold, Platinum)
📅 Time-based Analysis
Weekly revenue trends and quarterly comparisons
🎯 Interactive Filters
Dynamic slicers for:
Quarter
Gender
Card category
Week start date
🛠️ Tools & Technologies
Power BI (Data Visualization)
SQL (Data Extraction & Integration)
DAX (Data Analysis Expressions)
📌 Key Insights
Business and high-income customers contribute significantly to overall revenue
Swipe transactions dominate compared to other transaction modes
Middle-aged customers (30–50) show higher spending patterns
Certain card categories generate more revenue despite fewer users
An interactive dashboard built using Microsoft Power BI and connected to SQL to analyze credit card customer data and transaction behavior.

This project focuses on generating insights from financial data and enabling real-time analytics through automatic data refresh.
